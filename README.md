# starsoft-frontend-challenge

> Marketplace de NFTs fiel ao Figma, com carrinho fluido e sensação de aplicativo nativo.

## Problema

Marketplace de NFTs fiel ao Figma, com carrinho fluido e sensação de aplicativo nativo.

## Solução

Next.js com Redux Toolkit (Duck Pattern), paginação server-side da API oficial, drawer com Framer Motion e animação fly-to-cart no fluxo de compra.

## Stack

- Next.js
- TypeScript
- Redux
- Framer Motion
